## `01` / ABOUT
从真实世界的影像采集，到视觉模型的评测验证，再到端侧推理的工程优化。
Light Witness Lab is an independent open-source lab exploring imaging, model validation, and efficient on-device intelligence.
我们关注技术如何从概念走向真实设备：以应用验证体验，以实验检验模型，以工程优化推理。

## `02` / PROJECTS
### ◉ [street-snap](https://github.com/light-witness-lab/street-snap)
**Documentary Camera · 纪实摄影相机**
An open-source camera built for the serendipity of street photography.
- 28 / 35 / 50mm focal-length perspectives
- Snap-oriented shooting controls
- Custom LUTs for image rendering

[Explore Repository →](https://github.com/light-witness-lab/street-snap)

---

### ◈ [edge-model-solutions](https://github.com/light-witness-lab/edge-model-solutions)
**Visual Model Validation · 视觉模型验证方案**
Practical visual & multimodal model sets for camera applications, focusing on transparent testing and failure analysis.
- 版本化模型制品与独立权重许可声明
- 基于实测的效果评估与失效案例记录
- 可复现的模型基准测试

[Explore Repository →](https://github.com/light-witness-lab/edge-model-solutions)

---

### ⌘ [inference-engineering](https://github.com/light-witness-lab/inference-engineering)
**On-device AI · 端侧推理优化**
Researching local LLM runtimes, edge inference engines, and hardware-aware optimization.
- **Runtimes** — llama.cpp, MLC LLM, ExecuTorch, ONNX Runtime, LiteRT
- **Edge & local serving** — SGLang, vLLM, TensorRT-LLM, MLX
- **Optimization** — Quantization, KV cache, attention, and heterogeneous execution
- **Evaluation** — Reproducible benchmarks for latency, memory, throughput, and power

研究本地大模型运行时、边缘推理引擎与硬件感知优化。围绕量化、KV缓存、注意力机制与异构调度，构建可复现基准，实测延迟、内存、吞吐与功耗表现。

[Explore Repository →](https://github.com/light-witness-lab/inference-engineering)

## `03` / ENGINEERING PRINCIPLES
- **Open by default** — 开放实现，共享工具与知识。
- **Evidence over claims** — 用评测与记录说明能力边界。
- **Reproducible by design** — 让实验可验证，让结果可复现。
- **Built for real devices** — 面向真实场景，而非停留在纸面指标。
