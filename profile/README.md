## 🔭 关于本社区
光证实验室是专注人文纪实与街拍方向的开源社区。
我们开发相机应用、测光工具、EXIF辅助工具、胶片模拟算法，沉淀纪实摄影知识库。
途帧（途帧App）为本社区旗下核心项目。
